# Number of doses of PMC

Number of doses of PMC

## Usage

``` r
commodity_doses_pmc(pmc_cov, par_pmc, n_rounds = 3)
```

## Arguments

- pmc_cov:

  PMC coverage. Numeric scalar or vector.

- par_pmc:

  Population at risk within pmc-eligible age range. Numeric scalar or
  vector.

- n_rounds:

  Number of pmc rounds per year. Numeric scalar or vector.

## Value

The total number of pmc doses delivered.
