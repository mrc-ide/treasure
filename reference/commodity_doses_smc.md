# Number of doses of SMC

Number of doses of SMC

## Usage

``` r
commodity_doses_smc(smc_cov, n_rounds, par_smc)
```

## Arguments

- smc_cov:

  SMC coverage. Numeric scalar or vector.

- n_rounds:

  Number of SMC rounds per year. Numeric scalar or vector.

- par_smc:

  Population at risk within SMC-eligible age range. Numeric scalar or
  vector.

## Value

The total number of SMC doses delivered.
