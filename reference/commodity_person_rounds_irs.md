# Number of people-rounds of IRS

Number of people-rounds of IRS

## Usage

``` r
commodity_person_rounds_irs(irs_cov, n_rounds, par)
```

## Arguments

- irs_cov:

  IRS coverage per year. Numeric scalar or vector.

- n_rounds:

  Number of spray rounds per year. Numeric scalar or vector.

- par:

  Population at risk estimates. Numeric scalar or vector.

## Value

The total number of person-rounds of IRS protection.
