# Cost Microscopy

Cost Microscopy

## Usage

``` r
cost_microscopy(n_tests, cost_per_slide = 0.26, input_year = 2007, ...)
```

## Arguments

- n_tests:

  Number of tests performed. Numeric scalar or vector.

- cost_per_slide:

  Cost per slide diagnostic performed. Numeric scalar or vector.

- input_year:

  Year the unit costs are reported in

- ...:

  Additional arguments passed to \`inflation_adjust()\`

## Value

Microscopy costs

## References

**Microsopy_unit_cost**

Estimate of \$0.26 per slide taken from Lubell et all (2007)

<https://pubmed.ncbi.nlm.nih.gov/18165484/>.
