# World Bank Consumer Price Index (CPI)

Regional CPI by year, taken as median of country-level CPI

## Usage

``` r
cpi
```

## Format

A data frame with 1816 rows and 10 variables:

- year:

  Year

- region:

  Region

- cpi:

  Consumer Price Index

## Source

<https://data.worldbank.org/indicator/FP.CPI.TOTL.ZG?locations=ZG>

## Details

Data from: World Bank.
