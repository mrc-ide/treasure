# WHO CHOICE inpatient/outpatient costs.

Data from: World Health Organization. Cost effectiveness and strategic
planning (WHO-CHOICE). 2021-02-12

## Usage

``` r
who_choice
```

## Format

A data frame with 1816 rows and 10 variables:

- region_country:

  Region or country

- iso3c:

  Country iso3c code

- type:

  Inpatient or outpatient

- level:

  Health facility level

- model:

  Model prediction

- sample_mean:

  Mean value from sample

- upper_95_ui:

  High estimate (95 percent uncertainty interval)

- lower_95_ui:

  Low estimate (95 percent uncertainty interval)

- sd:

  Standard deviation

- definition:

  Definition

## Source
